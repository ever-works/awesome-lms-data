## Overview

Edmingle is an AI-driven, analytics-centric training management platform that transcends traditional LMS boundaries, enabling training organizations to deliver courses and programs effectively.

## Key Features

- Live Classes
- Attendance Tracking
- API Integration
- E-Commerce
- SMS Notifications
- Course Management
- SCORM Compliance
- User Permissions
