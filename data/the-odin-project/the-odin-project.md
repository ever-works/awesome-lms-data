## Overview

The Odin Project is a free, open-source online curriculum for learning web development, designed as an alternative to expensive bootcamps.

## Features

- Comprehensive full-stack JavaScript and Ruby on Rails curriculum
- Project-based learning
- Community support via Discord and forums
- Completely free of cost
- Curated external resources presented in logical order

## Pricing

Completely free.
