## Overview

QST is an open-source online assessment software supporting everything from quick phone quizzes to large-scale, high-stakes, proctored desktop testing.

## Features

- Online assessment software
- Quick quizzes to large-scale proctored testing
- Secure and economical testing
- Self-hosted deployment
- Web-based interface

## Deployment

Self-hosted
