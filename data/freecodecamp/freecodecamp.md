## Overview

freeCodeCamp is a non-profit community that helps people learn to code for free by completing coding challenges and building projects.

## Features

- Comprehensive curriculum covering web development, data science, and more
- Project-based learning
- Community support and study groups
- Real-world non-profit projects
- Free certifications
- Open source codebase

## Pricing

Completely free.

## License

Open source. Repository: https://github.com/freeCodeCamp/freeCodeCamp

Cloud-hosted (SaaS); open-source repository available for self-hosting.
