## Overview

Teachmint X is an AI-Powered connected classroom technology platform designed to transform traditional classrooms into technologically advanced, connected learning spaces.

## Features

- Student Tracking
- Lesson Plans
- User Permissions
- Reporting and Analytics
- K-12 support
- Interactive Whiteboard
- User Collaboration
- Lesson Planning

## Target Segments

- StartUps
- SMBs
- Mid-Market
- Enterprises
